Text message pricing

{{ content_metadata( data={ "Last updated": [ last_updated, sms_rate.valid_from ]|max|format_date_normal } ) }}

A single, 160-character text message costs {{ sms_rate }} (plus VAT).

You only have to pay for text messages if you exceed your free text message allowance.

{% if sms_rate != 2.4 %}

On 1 April 2026:

  • the cost of a single text message will go up to 2.4 pence
  • we’re reducing the free allowance for central government departments and national organisations
{% endif %}

A text message may cost more, or use more of your free allowance, if it:

  • is longer than 160 characters
  • is written in a language other than English
  • uses certain signs and symbols
  • sent to an international phone number

We’ll tell you how many text messages your template may count as before you send it.

It does not cost you anything to receive text messages.

Long text messages

If a text message is longer than 160 characters (including spaces), it counts as more than one message.

Text messages in a language other than English

Most English language text messages use a set of standard letters and symbols.

Languages such as Welsh, Arabic and Mandarin use non-standard characters.

Including a non-standard character in a text message changes the way we have to charge for it.

Anything longer than 70 characters (including spaces) counts as more than one message.

Standard letters and symbols

Characters that do not affect the cost of a text message include:

  • uppercase letters A to Z
  • lowercase letters a to z
  • Ä, É, Ö, Ü, à, ä, é, è, ì, ò, ö, ù, ü
  • numbers 0 to 9
  • common punctuation, for example . , ! ?
  • single and double quotation marks
  • dashes

Signs and symbols

The following signs and symbols count as 2 characters each:
[]{}^\|~€
